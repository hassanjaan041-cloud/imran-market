# 🛍️ Decoration Shop Management & E-Commerce System

A complete full-stack web application for managing shop inventory, local sales, rental properties, and international e-commerce orders.

## 🚀 Tech Stack
* **Frontend:** React.js, Vite, CSS3
* **Backend:** Node.js, Express.js
* **Database:** SQLite (Local relational database)

## ⚙️ How to Run (For Shopkeeper)
Double-click on **`Start_Shop_App.bat`**. 
The script will automatically open VS Code, start the backend, start the frontend, and open the browser.

## 🛠️ Developer Setup (Manual)
* **Backend:** `cd backend` -> `npm install` -> `npm start` (Port 5000)
* **Frontend:** `cd frontend` -> `npm install` -> `npm run dev` (Port 3000)

## 🌍 Online Access (Ngrok)
To share the storefront online, open a new terminal and run:
`ngrok http 3000`
